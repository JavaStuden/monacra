日期：2026-10-25（Asia/Shanghai）。结论：**GO，客户评审可点击原型**。

## 改动

1. 分类由侧边列表改为3×2图标网格，四主类切换、子类与全部商品、畅销、优惠均可操作；保留搜索、相机、搭配与最近浏览。
2. 首页新增“الأكثر طلباً”及collection/bestsellers完整榜单。只聚合本浏览器原型内已付款且未取消订单的原始下单件数，订单ID去重、有效SKU及数量校验、稳定排序，无数据有真空态。榜单标明演示数据，不伪装全店实时销量；不扣售后退回量，不代表净销量。
3. 自托管Google Fonts Noto Sans Arabic两子集，共197,376字节，原OFL许可随包。正文500、操作/商品名600、标题700，输入16px/52px高，手机商品名14–15px、底栏11–12px；加深辅助文字，移除Arabic标题的旧Georgia覆盖。SVG品牌字标保留。
4. 分类、图片、表单、按钮与卡片统一12–16px柔和圆角；保留首页Banner原构图、Logo透明资产、图片等比与付款前地址步骤。
5. UI总览新增畅销入口，共60个页面/状态预览；命名路由仍52种。
