# Monarca v4.7.0 · 美元与双供货渠道

**v4.7.0 · 2026-10-27（Asia/Shanghai）**。本版为美元演示目录与伊拉克／中国双供货渠道；沿用已确认的 Monarca 视觉、Arabic RTL／English LTR、较小 Zain 字号和一页结账。价格是独立配置的 USD 样例报价，不是汇率换算或商家正式价目。

USD样例报价集中在`app.js`的`M.commerce.prices`；14款商品不是把原数字更换币种，也没有引用实时汇率。商家正式美元价目、库存和费用需在真实产品中接入。新USD命名空间与旧`monarca-iraq-v4`分开，避免将历史原型金额误认作美元；旧键不覆写、不删除，语言偏好继续沿用。

首页和分类提供两来源入口；总览更新为67卡。商品2／5为中国预订，其余12款为伊拉克现货。混合订单按两组配送说明预付，来源与时间快照贯穿成功页、订单、跟踪和收据。运费／优惠只按本次选择计算；COD提交和落单前再检查，未选择的中国商品留袋，不影响纯伊拉克订单COD。美元退货按美分累计分摊，避免四舍五入丢失或虚构退款。
