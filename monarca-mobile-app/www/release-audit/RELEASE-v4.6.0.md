## 本版六项需求

| 需求 | 当前实现与范围 |
| --- | --- |
| 现货 COD 与预售限制 | 14款中 ID 2／5 演示预售，其余现货。只有本次购买的全部商品现货可选 COD；预售或混合禁用，并在提交／确认前复核。未选中预售不影响现货单。 |
| 真实菜单 | 首页菜单进入 `menu`，提供账户、订单、地址、支持、语言和设置入口。 |
| 中性阿拉伯语 | 固定界面文字通过本地化层使用中性措辞；用户输入、顾客资料和订单快照不翻译改写。已抽查真实页面；完整母语审阅待后续测试。 |
| English 切换 | `region` 在 Arabic RTL／English LTR间切换并保存偏好；`lang=ar/en`可直接指定。伊拉克、IQD和+964不变，不执行换汇。 |
| Zain 自托管 | 官方Google Fonts Zain，400／700、Arabic／Latin共四个原始WOFF2，101,532 bytes；`font-display: swap`。OFL 1.1、官方URL、内部family／weight和SHA-256见 `assets/fonts/SOURCE-Zain.md`。 |
| 一页结算 | 地址新增／选择、配送、付款、商品金额、条款和确认合并在一页；卡校验后直接确认，无支付OTP。旧`payment`／`payment-auth`链接进入统一表单。 |

## 订单与资金状态

- 新 COD：`status=placed`、`paymentStatus=cod_due`、`paidTotal=0`，无`paidAt`／`transactionId`。成功提示、订单和收据区分订单金额、已付与应付。
- 配送演示不代表收款。未收款 COD 取消不建退款；送达后退货走 `noRefund`，完成时无退款记录。
- 商品折后金额按订单快照分摊；可退金额单独按实付金额分摊，避免折扣COD商品显示0元或虚构退款。
- 旧待付款卡单复用原订单编号、商品／地址／金额快照；确认成功后通过`cartConsumed`／`couponConsumed`只扣一次。拒付不消费购物袋或券。
- M10在COD确认或卡成功时消费；预购／混合单仅允许测试卡。当前库存、订单和金额仍是本地原型数据。
