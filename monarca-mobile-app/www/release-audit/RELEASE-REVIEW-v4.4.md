## 本轮修复与完善

- 地址选择使用明确的结算入口；从账户新增地址后返回地址簿，避免沿用先前结算意图。
- 新订单创建快照前校验体验条款确认；原待付款单可继续，拒付重试复用同一订单。
- 新增城市／区县／乡镇自由输入，保留配送区域计算费用；地点、备注、赠礼和优惠信息进入订单及凭据。
- 修正修改手机号时重复 +964、金色耳环及棕色夹克的颜色／检索描述。
- 自动免普通运费不再伪装成可领取的免邮券；兼容旧钱包和历史待付快照。
- 商品图共用等比 SVG 裁片。鞋、耳环及其复用款换用 1254 × 1254 AI 原型图，详情如实说明来源。其他商品仍为客户参考图裁片。客户确认的首页、Logo、Banner 构图保留。

## 本轮浏览器实际点击

环境：Windows Codex内置浏览器、本地HTTP预览；核心路径390 × 844，另有320px结算人工查看。

1. 首页商品 → 选择M码 → 加购 → 购物袋；新增同规格合并为两件。
2. 取消勾选包袋，只结算两件衬衫：370,000 − 37,000 M10 + 5,000加急 = **338,000 IQD**。
3. 结算 → 新地址；遗漏locality显示错误，补填“أبو غريب”后正常返回结算；阿拉伯数字手机号归一为+964。
4. 填订单备注及礼品留言，选Mastercard；未勾选体验条款时阻止继续。
5. 错误CVV → 纠正 → 错误OTP → 拒付 → 原订单重试 → 成功，订单编号保持`M-DEMO-415205388`，金额338,000不变。
6. 凭据显示完整地点、M10、备注和礼品留言；未勾选包袋仍在购物袋。
7. 账户 → 地址簿 → 新建并保存，返回地址簿；不再错误跳回结算。
8. 阿拉伯数字登录 → 编辑号码；已确认单一+964前缀。优惠中心显示自动免邮说明，已用M10位于已用状态。
9. 已送达示例订单`M-DEMO-1018` → 退货申请 → 审核 → 登记模拟退回单`RET-TEST-1042` → 收货检查 → 退款处理 → 完成；退款记录185,000 IQD、原Visa，明确无真实资金流转。
10. 首页、高清鞋／耳环、窄屏结算人工查看；图片自然比例，底部主操作与导航可用。

## 经营与设备边界

支付、账户验证码、识图、库存、物流、退款及客服均为本地模拟，无服务端订单／收款。只输入公开测试资料和虚构地址。普通／加急配送、优惠及退换货规则均待客户按真实经营确认。当前阿拉伯语面向伊拉克，尚无库尔德语版本；最终文案仍建议客户本地团队审核。

未执行原生App、真实手机软键盘／系统拍照权限、全部读屏操作、弱网、银行网关、真实物流与并发服务端验收。HTTP服务器预览不能替代域名HTTPS生产环境；图片上传入口可用于评审拍照搜索模拟，系统相机行为需在实际设备验证。

## 发布方案

经用户授权，将静态文件上传到服务器版本目录，并由现有站点的独立`/monarca/`软链接入口提供访问。逐文件SHA256校验后切换，保留可恢复的版本目录；发布失败撤回本次软链接。发布前后核对现有主页、`/anchor/`和Nginx配置哈希；不修改其他项目。实际发布编号及线上冒烟另见部署结果。
