# 商品短视频

2026-11-23：后台上传与网站播放已发布，uni-app 已完成代码和资源编译，现有 APK/IPA 未重新打包。

## 商家操作

1. 刷新 https://itsmonarca.com/admin/ ，编辑或新增商品。
2. 在 **Product video (optional) / فيديو المنتج (اختياري)** 选择一个 MP4 文件，再保存商品。视频上限 **20 MB**；建议竖屏、H.264 编码、6–15 秒。原有商品照片和颜色关联可同时保留。
3. 有视频的商品详情页显示静音循环的小窗，可关闭、重新打开或点开放大播放。没有上传视频的商品不出现小窗。网站尊重减少动态效果和省流量设置，浏览器省电模式可能要求手动点击播放。
4. 替换视频时重新选择文件并保存；移除时点 **Remove video / إزالة الفيديو** 后保存。取消编辑不会保存变更。

每个商品当前支持一段视频，供整件商品展示，不按所选颜色自动更换。不要将另一件商品的影片作为本商品展示。用户提供的参考截图不包含视频文件，本次没有给任何正式商品附加测试片。

## 兼容性与存储

- `Product.videoUrl` 是新增可空字段，旧商品保持无视频；旧版编辑请求省略视频时保留原视频。只有带管理 token 的上传/移除请求可以修改该字段，不能通过 JSON 指派外部网址或其他商品的存储路径。
- 视频保存在后端工作目录下 `./data/product-videos/`，可用 `monarca.product-videos.directory` 覆盖；文件使用随机 UUID 名称。接口为 `/api/v1/product-videos/{uuid}.mp4`，提供 `video/mp4`、公开缓存和字节范围读取，支持视频拖动和 Safari 的分段请求。
- 服务端验证 MP4 容器头、完整顶层区块和 `moov`/`mdat`，不依赖上传者提供的扩展名和 MIME。不会自动转码，也不保证所有 MP4 编码都能被所有手机播放；优先导出 H.264。
- 替换或移除时保留旧视频文件，避免已经打开的页面和缓存失效；失败的新上传会清理。若以后清理存储，应只清理无商品引用的旧视频，并先备份。
- 单文件请求上限改为 20 MB，整次请求 52 MB；图片仍单独限制为每张 5 MB、最多 6 张。Nginx 上传请求上限对应改为 52m。
- uni-app 已启用 `VideoPlayer`，小窗位于图片 swiper 外，使用 `cover-view` 显示按钮；打开完整图片图库或离开页面时暂停视频。原生播放器需要在新安装包内验证。参考 [DCloud 视频组件文档](https://uniapp.dcloud.net.cn/component/video.html)。
