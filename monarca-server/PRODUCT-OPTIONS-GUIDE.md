# 商品尺码、颜色及专属尺码表

2026-11-24：后台与正式网站已发布；uni-app 源码、H5 和 App 资源编译完成，现有安装包尚未重打包。

## 后台操作

刷新 https://itsmonarca.com/admin/ ，打开商品编辑页：

1. **Available sizes / المقاسات المتاحة**：直接输入该款实际尺码，用逗号分隔，或使用 `XS–4XL`、`M–4XL`、`36–42`、`One size / مقاس موحّد` 按钮。支持数字、XXL 等自定义尺码；不需要修改代码。最多 24 个尺码，每个最多 16 字符。阿拉伯逗号也可使用。
2. **Temporarily unavailable size / مقاس غير متوفر مؤقتاً**：保留原有的单个缺货尺码设置；选 `All selected sizes available / كل المقاسات المحددة متوفرة` 可清除缺货标记。删除一个尺码时，其旧缺货标记会一并清除。
3. **Available colors / الألوان المتاحة**：现有 20 个常见颜色，包括红、白、蓝、藏蓝、粉、紫、绿、酒红等。勾选该款实际售卖的颜色。
4. **Add a custom color / إضافة لون مخصص**：输入颜色名称并选择色块，可选填英文名，再点击添加。每款最多选 20 色；不同款即使使用相同的自定义色名称，也按该款自己的资料显示。颜色照片下拉框会同步包含新增颜色，可继续关联照片。
5. **Size chart for this model / جدول قياسات هذا الموديل**：上传该款真实尺码表的 JPG/PNG，最多 5 MB。尺码表与商品照片分开保存，不占用六张商品图库位置。可填写最多 2,000 字符的测量说明、厘米/英寸等单位；移除表格后需点击保存才会生效。

顾客点击商品的尺码指南，将看到该款自己的图表和说明。没有图表及说明时，页面明确提示联系商家，不再提供统一的示例胸围等数值。

本次没有批量更改实际商品的尺码、颜色、库存或价格，也没有将本地测试尺码图上传到正式商品。商家需按每款真实库存进行选择。库存数量仍是商品总库存，未新增每个“颜色 × 尺码”组合的独立库存。

## 兼容与实现

- 保留 `colors`、`sizes` 原有逗号字符串，增加 `colorOptions` 元数据（`key/nameAr/nameEn/hex`）和只读 `sizeChartUrl`。旧版编辑器省略新字段时保留现有选项、图表、说明及视频。
- 颜色字符串扩为 512 字符，尺码字符串扩为 512，测量说明扩为 2,000；新增颜色元数据列 8,000 字符。旧数据保留，新字段可空。
- 常见颜色代码的含义保持固定；自定义颜色的名称、代码、色值及数量均经过验证。拒绝 HTML 标签、非法色值和 `__proto__` 等保留键。客户端再次校验媒体路径和颜色元数据。
- 图表使用已验证的图片上传服务，服务端重新编码图片，随机 UUID 路径；不接受由 JSON 任意指派外部或其他商品的图表网址。
- 整个 multipart 请求上限调整为 58 MB，容纳六张图片、20 MB 视频及独立尺码表；各文件原有限制仍分别生效。
- 网站商品、颜色图片说明、购物车和订单文字支持新颜色；尺码筛选依据实际商品选项。uni-app 增加 `pages/size-guide/index`，支持查看及放大图表。
